# Project 1 — Horizon Travel

## Theme
A professional travel agency website that introduces destinations and helps customers explore available travel packages.

## Client Request
> "I want a complete website for my travel agency. The website will initially be static, but later we may add CSS, JavaScript, and a booking system. Please build the HTML structure in a way that another developer can easily style and expand later."

## HTML Requirements
Demonstrate proper usage of:
- **Semantic HTML**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` where appropriate
- **Headings**: Proper hierarchy (`<h1>` to `<h6>`)
- **Text Elements**: Paragraphs (`<p>`), Lists (`<ul>`, `<ol>`, `<dl>`)
- **Interactive Elements**: Links (`<a>`), Buttons (`<button>`)
- **Media**: Images (`<img>`) with meaningful `alt` text
- **Forms**: Labels (`<label>`) with appropriate input types (`<input>`, `<textarea>`, `<select>`)
- **Data Display**: Tables (`<table>`) where useful

### Constraints & Guidelines
- **No CSS**: Do not use custom CSS or frameworks (e.g., Tailwind CSS).
- **No JavaScript**: Keep the document purely structural.
- **No Div Soup**: Avoid wrapping everything inside generic `<div>` elements; use semantic containers.
- **Strict Hierarchy**: Do not use headings randomly based on default sizing.
- **Accessibility**: Never leave `alt` attributes empty or non-descriptive.
- **Functional Anchors**: Ensure navigation links connect to valid target sections or pages.
- **Focus**: Prioritize clean, standard-compliant HTML structure over visual presentation.
