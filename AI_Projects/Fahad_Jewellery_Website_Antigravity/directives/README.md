# Directives (Layer 1)

This directory contains Standard Operating Procedures (SOPs) written in Markdown.

## Structure of a Directive
- **Goal**: What needs to be accomplished
- **Inputs**: Required inputs, parameters, configuration, or environment variables
- **Execution Tools**: Python scripts in `execution/` to run for doing deterministic work
- **Outputs**: Expected output format, deliverables (e.g. Google Sheets/Slides, exported files)
- **Edge Cases & Error Handling**: Lessons learned from self-annealing iterations
